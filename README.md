# Schafer Farm

Single-page sample website for Schafer Farm, an animal feed source in southeast Ohio.

- **Phone:** (740) 509-3615
- **Google listing:** "Schafer farm", category *Animal feed store*, no address, hours, photos, reviews or website listed
- **Location:** listed only as "OH". The 740-509 exchange is Caldwell, Noble County, according to a reverse-lookup site. That's unconfirmed, so the site just says "southeast Ohio".

## Structure

- `index.html`: the whole site. CSS is inline and there's no build step. It uses a barn red / burlap / Ohio-hill-green palette with Zilla Slab and Libre Franklin, and has light and dark themes.
- `img/`: stock photos from Unsplash (hay bales, cattle, sheep, hens, feed sacks, farmstead). They're credited in the footer as representative, not the farm's own.

## Sections

1. Hero with call and text buttons
2. At-a-glance strip
3. The farm: honest, generic intro
4. Feed by animal (cattle, horses, goats & sheep, poultry, hogs), each with "ask about…"
5. How it works: call or text, we confirm, pick up
6. Text-an-order builder: pick animals and amounts, and it opens a prefilled SMS to (740) 509-3615
7. FAQ
8. Contact band with the big phone number

## Data sources and honesty

No Facebook page, website or other listing for this farm turned up. There are several unrelated Ohio "Schafer/Schaefer" farms (Atwater Herefords, Shelby County dairy, Trenton farm market), and they were excluded. No products, prices, hours, history, family names or reviews were invented. All availability copy says "call or text". Swap in the farm's real photos, products and address once the owner provides them.

The Sendra tracking script is included before `</body>`.
